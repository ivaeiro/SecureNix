# 🛡️ SecuriNix

**Automated Linux Security Hardening Toolkit**

SecuriNix is an open-source project designed to automate Linux security hardening, simplify security auditing, and help administrators apply consistent security configurations.

## ✨ Features

- 🔐 Automated security configuration
- 🛡️ SSH security hardening
- 🔥 Firewall configuration
- 👤 User and permission auditing
- 📋 CIS Benchmark compliance checks
- 📝 Security audit reports

> Features are under development. Availability depends on the current project version.

## 🎯 Objectives

- Automate repetitive Linux hardening tasks.
- Improve system security through consistent configurations.
- Reduce manual configuration errors.
- Provide clear and actionable security audit results.

## 🐧 Supported Systems

Support for specific Linux distributions will be documented as the project develops.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ivaeiro/securenix.git
cd securenix
```

Follow the installation and usage instructions provided for your distribution and project version.

## ⚠️ Disclaimer

SecuriNix is intended for authorized security administration, system hardening, and educational purposes.

Always review configuration changes before applying them to production systems. Test the tool in a controlled environment and maintain a recovery plan before modifying critical system settings.
